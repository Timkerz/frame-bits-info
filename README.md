# FRAME-bits uploader — information pages

Публичные информационные страницы личного загрузчика FRAME-bits.

## Включение GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.

После успешного развертывания предполагаемые адреса:

- Главная: https://timkerz.github.io/frame-bits-info/
- Конфиденциальность: https://timkerz.github.io/frame-bits-info/privacy.html
- Условия: https://timkerz.github.io/frame-bits-info/terms.html

Адреса действуют после включения Pages и успешного развертывания, не после одного лишь commit.

Для OAuth Branding используется точное имя FRAME-bits uploader.
Если Google потребует подтвердить домен, подтвердите владение через Search Console;
не указывайте github.io как собственный домен и не подставляйте чужую политику.

Здесь хранятся только публичные HTML/CSS и документация. Не добавлять токены,
OAuth JSON, исходные видео, приватную очередь и журнал загрузок.

Политика описывает текущий загрузчик. Оператор должен выполнять указанный порядок
удаления данных; автоматическая очистка журнала в загрузчике пока не реализована.
Отключение автоматизации не отменяет уже назначенные публикации в YouTube.
