Конфиденциальность

Эта политика описывает FRAME-bits uploader — личный инструмент владельца канала FRAME-bits. Ответственный за работу приложения доступен через обращения в GitHub. Приложение использует YouTube API Services; к обработке данных Google применяется политика конфиденциальности Google.

Данные и цели обработки

  • Идентификатор и публичное обозначение авторизованного YouTube-канала: для проверки, что видео отправляется в FRAME-bits.
  • Подготовленные владельцем видео, заголовки, описания, время публикации, настройки аудитории и синтетического контента: для передачи в YouTube.
  • OAuth access token и refresh token, а также параметры OAuth-клиента: для выполнения разрешенных владельцем запросов без повторного входа при каждом запуске. Пароли Google не запрашиваются и не сохраняются.
  • Идентификаторы загруженных видео, ответы API о статусе, время операций и контрольные суммы файлов: для подтверждения результата и защиты от дублей.
  • Обращения, отправленные через GitHub: для ответа на обращение.

Хранение и получатели

Доступ OAuth первоначально оформляется локально на компьютере владельца. Refresh token хранится в локальном файле и, после настройки, в GitHub Actions Secrets закрытого репозитория. Access token используется во время запуска. Очередь и журнал хранятся в закрытом репозитории; их история может сохраняться в Git. Видео временно скачивается на исполнитель загрузчика и передается в Google/YouTube. Исходный файл также может храниться в выбранном владельцем файловом хранилище.

Данные обрабатывают Google/YouTube, GitHub и выбранный владельцем поставщик исходных файлов в объеме, необходимом для работы. К закрытому репозиторию и его журналам могут иметь доступ владелец и уполномоченные им администраторы. Приложение не продает данные, не использует их для рекламы и не передает их для обучения моделей искусственного интеллекта. Использование информации из Google API ограничено назначением загрузчика и требованиями Google API Services User Data Policy, включая Limited Use.

Сроки и удаление

Временный рабочий файл удаляется по завершении процесса; жизненным циклом облачного исполнителя управляет GitHub. Исходные видео в хранилище и записи очереди удаляет владелец. Журнал и доступы сохраняются, пока необходимы для действующей очереди и предотвращения повторной загрузки; автоматическая очистка исторических записей сейчас не реализована. Владелец должен удалять ненужные данные и устаревшую историю при завершении работы с ними.

Для удаления данных или прекращения обработки обратитесь через GitHub Issues. После запроса оператор отключает загрузчик, удаляет соответствующие локальные токены, секреты, данные очереди и журнала, а при необходимости — их доступную Git-историю, в течение семи дней. Резервные копии и технические журналы поставщиков могут сохраняться по их собственным правилам. Удаление локальных данных не удаляет уже загруженные видео с YouTube: ими управляют отдельно в YouTube Studio.

Отзыв доступа

Доступ можно отозвать самостоятельно в разделе подключений Google-аккаунта. После отзыва загрузчик не сможет продолжить авторизованные запросы. Отзыв доступа сам по себе не удаляет локальную очередь, журнал или опубликованные видео; для их удаления используйте описанный выше порядок.

Данные этого сайта

На информационных страницах нет собственных форм, аналитических счетчиков, рекламы или скриптов отслеживания. Сайт размещается на GitHub Pages; GitHub может обрабатывать IP-адрес и технические сведения запросов согласно своей политике конфиденциальности. Переходы на внешние сайты регулируются их правилами.

Безопасное обращение

GitHub Issues — публичный канал связи. Не размещайте там токены, адреса электронной почты, приватные видео или иные личные данные. Для запроса удаления сначала укажите только тип запроса; порядок безопасного подтверждения и передачи деталей согласуется отдельно.
