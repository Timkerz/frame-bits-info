Свое расписание.

FRAME-bits uploader предназначен для загрузки подготовленных видео на канал @FRAME-bits и назначения времени их публикации.

Приложение использует YouTube API Services. Владелец подтверждает доступ через Google OAuth, затем загрузчик обрабатывает одобренные записи своей очереди. Доступ к чужим каналам и открытая регистрация не предусмотрены.

Что делает приложение

  • Проверяет, что авторизован именно канал FRAME-bits.
  • Загружает выбранный владельцем MP4, заголовок и описание.
  • Передает настройки аудитории, отметку о синтетическом контенте и время публикации.
  • Хранит журнал загрузок для защиты от повторов.

Какие разрешения запрашиваются

youtube.upload — загрузка видео; youtube.readonly — чтение идентификатора и названия канала для проверки получателя. Пароль Google приложению не передается.

Как начать и остановить работу

Авторизация выполняется владельцем через локальную программу, а загрузчик может запускаться в его закрытом репозитории GitHub Actions. Этот сайт только описывает приложение: формы входа и приема файлов здесь нет. Чтобы остановить новые загрузки, владелец отключает workflow. Уже назначенные публикации отменяются отдельно в YouTube Studio.

Перед выдачей доступа ознакомьтесь с политикой конфиденциальности и условиями использования. Настройка приложения и проверка загрузки выполняются отдельно; наличие этого сайта не означает, что автоматическая публикация уже активна.
